## 📌 About The Project

This is a browser-based **Tic Tac Toe** game where two players can compete against each other.

The project focuses on creating a clean user interface while implementing the complete game logic using JavaScript.

### ✨ Features

* 🎯 Two-player gameplay
* 🏆 Automatic winner detection
* 🤝 Draw detection
* 🔄 Restart / New Game functionality
* ⚡ Instant game updates
* 📱 Responsive design
* 🎨 Clean and simple UI

## 🎮 How To Play

1. Player **X** starts the game.
2. Players take turns selecting an empty box.
3. Get **three matching symbols in a row** — horizontally, vertically, or diagonally.
4. The first player to do so wins! 🏆
5. If all boxes are filled without a winner, the game ends in a draw. 🤝
